Build and test Expo and React Native iOS apps on Linux

Expo and React Native let you write an iOS app on Linux, but building and running it needs Xcode, which needs macOS. With macbox, one command copies your checkout into a macOS VM on the same machine, builds it there with Xcode and CocoaPods, and opens it in a real iOS Simulator, while Metro keeps running on Linux.

{{meta}}

In short

  • mac-sim up && mac-sim run from the app's checkout: a Debug build in the simulator, with Fast Refresh from Linux.
  • MODE=release mac-sim run for a Release build; MODE=go mac-sim run for Expo Go.
  • The first build takes 2 to 15 minutes; later ones are incremental.

Before you start

  • A macbox VM with Xcode and the simulator pool, and the agent tools installed: macOS on Linux, Xcode on Linux, then ./macbox pool and ./macbox agents install.
  • The app's dependencies installed on Linux too (npm install, bun install, …), because Metro runs there.

Run the app

cd ~/code/my-app
mac-sim up                    # claim a simulator for this checkout and boot it
mac-sim run                   # build on the Mac, install, open; Metro runs here
mac-sim shot /tmp/home.png    # look at it

What mac-sim run does:

  1. Copies the checkout to the Mac, without node_modules, .git and generated ios/ and android/ folders. Uncommitted changes are included; nothing needs to be pushed. A gitignored .env is copied too.
  2. Installs dependencies there with the project's package manager, and runs expo prebuild and pod install when the app config or dependencies changed.
  3. Builds with xcodebuild for that simulator (x86_64, since the VM is an Intel Mac), installs and opens the app.
  4. Starts Metro on Linux from your checkout. The app reaches it through an SSH tunnel, so saving a file updates the app by Fast Refresh.

Run mac-sim run again after native changes: a new native dependency, a config plugin, app.json.

Release builds and Expo Go

CommandWhat you get
mac-sim runa Debug build with Metro on Linux and Fast Refresh
MODE=release mac-sim runa Release build with the JavaScript inside and no Metro: what users get. Check performance here; Debug builds and Expo Go add jank of their own
MODE=go mac-sim runthe app in Expo Go, at the version matching the project's SDK, installed for you. Only for apps without custom native code

Other project shapes

  • Bare React Native with its own ios/ folder in git: built as it is, with pod install but no prebuild.
  • Monorepos with several apps: run from inside the app's folder, or set APP_DIR.
  • Old libraries that import React Native's old headers ('RCTBridge.h' file not found): RN_FROM_SOURCE=1 mac-sim run builds React Native from source, slower.
  • Don't run npx expo run:ios on the Mac: it opens Simulator.app, which doubles the GPU's work for every simulator.

Check the UI, not just the build

mac-sim snapshot               # the accessibility tree, refs like @e4
mac-sim ad press @e4           # tap; also fill, scroll, swipe, back...
mac-sim open myapp://settings  # a deep link
mac-sim record /tmp/flow.mp4 10 &
mac-sim ad press @e4           # drive the flow while it records
wait; sim-fps /tmp/flow.mp4    # 60 fps and no dropped frames in every stretch?

Measure motion on the default 1x simulator; the 3x ones (mac-sim up --sharp) are for screenshots at a real iPhone's pixels. Need widgets, Live Activities, the Dynamic Island or push? mac-sim up --full. mac-sim logs shows the build, Metro and tunnel output when something fails.

Android from the same checkout

android-sim up && android-sim run does the same with an Android emulator on the host, if the Android SDK is set up (docs/agents.md).

Real phones and TestFlight

phone-build (the phone-builds skill) makes an .ipa for an iPhone or TestFlight with your eas.json profiles. It uses Expo's free monthly EAS cloud builds first, then builds locally: iOS in the macbox VM, Android on the host. Signing for a device needs Apple's paid Developer Program. See skills/phone-builds.

When you're done

mac-sim down    # stop Metro and free the simulator
mac-sim clean   # optional: delete this checkout's copy and build on the Mac (1 to 2 GB)
